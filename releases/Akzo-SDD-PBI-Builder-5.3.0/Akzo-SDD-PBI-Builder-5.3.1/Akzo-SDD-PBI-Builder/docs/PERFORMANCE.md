## PBI listing: 5.1.0 implementation versus current

Synthetic folders contain pbi.json plus eight 4 KiB documents. Median of 3 runs per size; the pre-change function is the 5.1.0 implementation from the repository baseline. Content reads and bytes count only file bodies opened by listing.

| PBIs | 5.1.0 time (ms) | Current time (ms) | Content reads (before → after) | Bytes read (before → after) |
| ---: | ---: | ---: | ---: | ---: |
| 100 | 2507.2 | 423.1 | 900 → 100 | 3,281,392 → 4,592 |
| 1000 | 28843.8 | 4113.0 | 9000 → 1000 | 32,814,893 → 46,893 |

| Evidence refresh | Cold: first fingerprint (ms) | Warm: unchanged files (ms) |
| --- | --- | --- |
| 3.1.0 (300 files) | 2936.2 | 1069.0 |
| Current (300 files) | 1238.0 | 1083.5 |

Warm refresh still hashes every indexed file on purpose: a changed file must never be reported current. The index lets the agent skip rereading
unchanged sources, which is where the time goes in a real refinement.

## Not measured here
Cold-start and warm-start analysis time, repository discovery time, files inspected, search calls, cache hit rate and refinement duration
happen inside Copilot. The agent now records files read, searches and evidence index entries reused in EVIDENCE.md, and Compare old & new
has columns for them (files_read, cache_entries_reused, cold_or_warm). No numbers are claimed until real runs are recorded.

## Approval and duplicate-evidence refresh: 5.2.0 versus 5.2.1
Paired medians from 7 alternating runs on the same Ready-for-Review PBI with three local evidence sources; the frozen 5.2.0 core and
current core were byte-identical to their benchmark copies. Approval count stayed at one.

| Operation | 5.2.0 time (ms) | 5.2.1 time (ms) | File reads (before → after) | Evidence source reads (before → after) |
| --- | ---: | ---: | ---: | ---: |
| Readiness + approval review | 74.81 | 82.18 | 19 → 21 | 3 → 6 |
| Refresh two entries for one duplicate source | 16.31 | 13.90 | 3 → 2 | 2 → 1 |

Review now hashes referenced source content, so a change can invalidate approval; the additional reads are intentional correctness work.
Timings are synthetic microbenchmarks, not end-to-end Copilot analysis measurements.
